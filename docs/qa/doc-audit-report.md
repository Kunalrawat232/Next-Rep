# Documentation audit report

> **Historical report.** It is superseded by a later documentation audit (recorded in `docs/learning/ai-log.md`, entry "Documentation audit and fixes"); the body below is kept unchanged as the record of this audit. Since then: the branches were merged and pushed (CI green), the voice parser, mic, `/api/parse`, the AI coach (`/api/coach`), the Groq second provider, the daily ceiling and the empty-workout rule were built, `agent_docs/` was added, and the suite grew from 3530 tests in 139 files to 4501 in 182 files (34 `*.qa.test.*` files). A Vercel preview has been deployed; production is not (production was deployed later).

State audited: branch `feat/home` at `d30e38b` (8 commits ahead of `main` at `1212fb8`, not pushed), `CLAUDE.md` modified and `AGENT_CONTEXT.md` untracked in the working tree. Read-only: nothing was edited, moved or deleted; this file is the only addition.

Scope: `CLAUDE.md`, `AGENT_CONTEXT.md`, `README.md`, everything under `docs/` (ADRs and `docs/learning/` included). Three read-only agents each checked one slice against the code, `package.json`, the migrations, the CI workflow and `git`; the highest-impact findings were then re-checked by hand (marked **verified**). Claims that were not re-checked are as reported by the agent and are labelled where they are uncertain. The current test run was not repeated for this audit: the latest full run (before this audit) was 139 test files and 3530 tests, all passing.

Single-source suggestions use short names: `package.json`, `.env.example`, `config.ts` (`src/domain/validation/config.ts`), `roadmap`, `A` (`AGENT_CONTEXT.md`), `C` (`CLAUDE.md`).

## Resolution

The developer asked for the documents to be updated according to this report, and that was done the same day by three agents with separate file lists, then reviewed. All 33 items and the duplicate pointers were addressed, with these differences:

- Not applied: the agent's claim that A §2 has no outbox (it is correct as written), and the ADR-009 "plain delete for now" line (still true: `src/data/remote/gyms.ts` does a plain delete; confirm with the developer before changing it).
- Applied with a note: lesson commit hashes in `lessons.md` that no longer exist after the history was squashed were replaced by the nearest commit holding the change (`75dd8c3`, `d69fa84`, `7bbfee2`).
- The "no body" commit rule now reads "no body, plus the Co-Authored-By attribution trailer when the harness asks for one", and is identical in CLAUDE.md, `working-agreement`, `coding-standards`, AGENT_CONTEXT.md and the `new-feature` skill.
- Still open and needing a decision, not a doc edit: widen the `.claude/settings.json` deny list to `.env.*` (X21), and confirm the gym-delete behaviour (X24).

The tables below are the original findings, kept as the record of what was wrong.
