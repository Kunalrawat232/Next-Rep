# Open questions

| Question                                                                                                              | Current default / decision                                                                                                                                               |
| --------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Auto-confirm voice sets after a short delay, or always tap?                                                           | **Always require a tap** for the MVP (confirmed 2026-10-08).                                                                                                             |
| Default unit                                                                                                          | **kg** (confirmed). Users can switch to lb in Settings; storage stays kg.                                                                                                |
| Which Gemini model on the free tier?                                                                                  | Set via `GEMINI_MODEL`; choose a fast, cheap model available on the free tier at build time. Never hardcoded.                                                            |
| Sync `raw_transcript` or keep it local only?                                                                          | **Sync it** (confirmed 2026-10-08): it is the user's own data and useful for debugging and QA. Revisit for privacy before submission.                                    |
| Rate limiting for `/api/parse` on serverless                                                                          | **Supabase table `api_rate_limits`** (decided 2026-10-08), because in-memory counters do not survive across serverless instances.                                        |
| Volume for dumbbell exercises (per dumbbell, so does it double?)                                                      | **Open.** Volume is not implemented until this is decided; see [ADR-002](../architecture/decisions/002-total-weight-convention.md).                                      |
| When to ask on a big jump (the design asks "did you mean 60?" for 45 kg after 60 kg, but that is inside the 40% band) | **Decided:** voice asks "did you mean 60?" on a big jump; a tapped weight only warns. See [weight rules](../domain/weight-rules.md) and [screens](../design/screens.md). |
| Making a gym edit atomic (it is several writes today)                                                                 | **Open.** Needs a database function; deferred on purpose in [ADR-009](../architecture/decisions/009-gym-bars-and-default-gym.md).                                        |
| Plate warning unit: follow the display unit or the spoken unit ("60 kilo" said by a user who shows lb)?               | **Decided:** it follows the display unit, with that unit's own plate pair (1.25 kg, 2.5 lb); see Plates in [weight rules](../domain/weight-rules.md).                    |
