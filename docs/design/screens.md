# Screens

| Screen            | Purpose                                                                                                                            | States to handle                                                     |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| Sign in           | Email + password sign-in                                                                                                           | loading, error                                                       |
| Your gym          | The bars added to your weights: barbell, optional EZ bar, Smith bar and others (built: `/gym`; the old `/gyms` addresses redirect) | first set-up, editing                                                |
| Home              | Start workout, last workout summary, suggestion                                                                                    | empty (first use), offline                                           |
| Active workout    | Current exercise, mic button, tap entry, logged sets, rest timer                                                                   | listening, parsing, confirm, ambiguity prompt, offline, sync pending |
| Exercise picker   | Search + recent exercises, add custom (built: `/exercises`, `/exercises/new`)                                                      | empty search, no results                                             |
| History           | Past workouts                                                                                                                      | empty, loading, offline (cached)                                     |
| Exercise progress | Chart of `total_kg` over time, PRs                                                                                                 | single data point, no data                                           |
| Settings          | Units (kg or lb), your bars, light-mode switch, sign out                                                                           |                                                                      |

| Home, WebHome, first-time                         | `/`, built (2026-10-10): "Ready to lift?", sync pill and the bar, today's suggestion (the first exercise of the last workout, with the reason and "It is a suggestion, you decide."), Start workout (opens that exercise; "Continue workout" while one is open), the last workout (day, up to 3 exercises as top set and set count), and small links to Your bars and Exercises. | ActiveWorkout, WebWorkout, SetConfirm, WebConfirm | `/workout`, `/workout/exercise`, `/workout/log`, built for tap logging (2026-10-09). The rest timer is built (2026-10-10): a "Rest" pill beside the gym chip opens presets of 60, 90, 120 and 180 s, a custom length of 30 to 900 s, +30 s and Stop; it counts down from a stored end time (so it is right after a reload or a locked screen), says "Rest over" and vibrates once where the browser can; it starts only when tapped and is not synced. | Progress, WebProgress                             | `/progress` and `/progress/:exerciseId`, built (2026-10-09): exercises logged on this device with their heaviest set; per exercise a chart of the top set per session (drawing hidden from screen readers), the records, and the same numbers as a table with PR badges. Navigation: bottom tab bar on phones (Home, History, Progress, Settings) plus a floating mic button as the phone's Workout entry (decided 2026-10-09), sidebar from 1024px (adds Workout).

Handoff 2 (2026-10-09, `handoff/2026-10-09/`, 60 artboards) adds designs for gym setup, exercise picker, tap logging with per-side breakdown, the two prompts ("did you mean 60?", "total or without the bar?"), history, settings (including light mode), sign-in and create-account with a check-your-email screen, and first-time, loading and error states. Its sign-in adds a "Forgot password?" link and a Show/Hide password toggle; password reset is out of scope ("Forgot password" is in the Won't have list of the [requirements](../product/requirements.md)), so the link is not built. Each screen is applied when its feature is built. Pages that do not exist yet show as disabled items, not as dead links.

Shared components: see [design system](design-system.md). Every screen needs empty, loading and error states with friendly, actionable microcopy.

Active workout (idle, listening, parsing, offline) → set confirmation with weight breakdown → "total or per side?" prompt → home with suggestion → history and progress chart → sign in and gym setup.
