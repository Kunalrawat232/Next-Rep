Handoff 2 (`handoff/2026-10-09/`, 60 artboards) adds designs for gym setup, exercise picker, tap logging with per-side breakdown, the two prompts ("did you mean 60?", "total or without the bar?"), history, settings (including light mode), sign-in and create-account with a check-your-email screen, and first-time, loading and error states. Its sign-in adds a "Forgot password?" link and a Show/Hide password toggle; password reset is out of scope ("Forgot password" is in the Won't have list of the [requirements](../product/requirements.md)), so the link is not built. Each screen is applied when its feature is built. Pages that do not exist yet show as disabled items, not as dead links.

Shared components: see [design system](design-system.md). Every screen needs empty, loading and error states with friendly, actionable microcopy.

## Priority order for designs

Active workout (idle, listening, parsing, offline) → set confirmation with weight breakdown → "total or per side?" prompt → home with suggestion → history and progress chart → sign in and gym setup.

**Workout screen changes (from a walk through as a user):** with no exercise chosen the second button is "Pick an exercise" (a link to the picker) instead of a dimmed "Tap instead"; the exercise name in the header has a chevron so it reads as tappable; the voice button is the only blue one and "Tap instead" is secondary; the list of sets for the chosen exercise is headed "Sets so far" (the name was shown twice); "End workout" does not wrap; the round Workout button is hidden on the `/workout` screens; and a rest starts by itself after each set (90 s, or the length last picked), with a switch in the Rest panel to turn that off.

**Progress graphs:** the Progress list starts with "Workouts per week" (bars, shown once there are two weeks of history) and each exercise row has a small trend line and a line such as "+10 Kg since 14 Sep" (green when up). The change is from the first to the latest point of what is drawn: the best set of each week, so training an exercise twice a week with a lighter second day does not look like a fall. The exercise page has a Weight / Reps toggle over the same weekly line; the table under it is still every session. Every drawing is hidden from screen readers, and the numbers are in text or in a table.

**Exercise history:** the Exercises screen and the workout's Choose exercise screen start with a "History" section above "Popular exercises": every exercise the person has logged, most recently done first, each with "Last done Sat 17 Oct". Six show, with "Show all N" / "Show fewer". It is not shown while searching or filtering, or before the first set is logged. It comes from the sets on the device (`exercisesByRecency` in `src/domain/history`), and the screen waits for them with its one loader.

**About and credits:** a page of its own (`/about`), reached from a plain link in Settings, under Appearance. It credits Gym visual (demonstrations, non-commercial), the exercises dataset (MIT), the free-exercise-db photos (Unlicense) and liquid-gl (MIT), and says the coach and the voice check use Gemini. Every outside link opens in a new tab with `noopener noreferrer`.

**Empty workouts:** "End workout" on a workout with no sets says "This workout has no sets, so it will not be saved. End it?", and ending it removes it instead of saving it. A workout with sets asks the usual question.
